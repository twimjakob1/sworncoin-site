What was checked, and what the check showed.

Each statement the project makes about Sworn carries the check that was run against it. Checks that failed stay in the record.

Live on the practice network

Deployed November 13, 2026 on Sepolia, Ethereum’s public test network. Its coins have no value. Each contract’s published source was verified as an exact match of the code on the network. Read back after deployment: 1,000,000,000 coins in all, 100,000,000 in the founder vault and 400,000,000 in the community pool.

Run the checks yourself

The model, the blockchain code, the tests, the runs that break each rule on purpose and the ledger are public. Anyone with a computer can rerun every result on this page.

No one outside the project has reviewed the code yet. Reports of faults are wanted, and each confirmed fault is entered in the ledger.
