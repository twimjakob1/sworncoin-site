Take Part

Testing needs issuers, checkers, readers and reviewers.

Sworn is in testing. Taking part costs nothing. It pays no coins and gives no claim to any later distribution.

Three ways to take part

Sworn runs on Sepolia, Ethereum’s public test network, where the coins have no value. The first ten issuers and the first checkers are being signed up now.

Issuers

You run a coin and want your promises about it believed.

  1. Choose one fact about your coin that you are willing to swear to.
  2. Build the statement with the tool on this page and send it.
  3. Your statement is posted on the test network with practice coins, checked, and opened to challenge.
Build your statement

Checkers

You can read a coin’s code and say what it does.

  1. Write with the chains and contract languages you read.
  2. You receive practice coins for your stake and statements to check.
  3. You record a finding, and other testers try to overturn it.
Write as a checker

Readers

You own a coin, or are deciding whether to.

  1. Pick one promise the coin’s issuer has made.
  2. Ask the issuer to put a bond behind it. A message you can send is on this page.
  3. Follow @sworncoin for the first statements.
Get the message

Reviewers: try to break it

The code is public and no one outside the project has reviewed it. Read it, run the tests and report any way to cheat the rules. Each confirmed fault is entered in the ledger with the reporter’s name.

Ask an issuer to swear

A message a reader can send to the issuer of any coin, by email or in public. Replace the bracketed words.

You have said publicly that [the promise, in the issuer's own words]. Will you put a bond behind it? Sworn (sworncoin.com) lets the issuer of a coin lock coins behind a statement for 30 to 365 days. An independent checker reads the coin, and the issuer loses the bond if the statement turns false.

What testing is

  • Testing uses practice coins. They have no value and cannot be exchanged for Sworn.
  • Taking part pays no coins and gives no claim to any later distribution.
  • The project sells no coins. Any message that asks for payment or for a wallet’s recovery words in Sworn’s name is a fraud.
  • Every number in the rules is a proposal until launch. What testers find can change them, and each change is entered in the record.
